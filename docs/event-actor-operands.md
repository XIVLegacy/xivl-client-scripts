# Event, Director and actor operands

These records describe positional arguments recovered from the retail 1.23b
client scripts and their supporting native and static-data contracts.
Each question has a row with meaning, values, evidence and confidence.

| Contract | Subjects |
| --- | --- |
| [Actor and Director initializers](actor-director-initializer-operands.md) | Map objects, Wolf and Garuda classes, door identity, Guildleve and quest Directors |
| [Command and NPC event operands](event-command-operands.md) | Gathering, teleport confirmation, Guildleve publishers, request wardens, key coffers, default talk and direct equipment repair |
| [Quest text and menu operands](quest-text-and-menu-operands.md) | Raid menu IDs, Task Board job names, Man2u0 text, item-use objectives and private areas |

Values observed in a call, compared by a branch or forwarded to another
consumer do not establish the full accepted producer domain. Unresolved
meanings remain explicit. The records distinguish recovered source behavior,
original instruction checks, static text expressions and native contracts
from historical client execution or server behavior.
